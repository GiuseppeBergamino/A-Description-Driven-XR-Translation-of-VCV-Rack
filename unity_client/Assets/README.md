# VeryVCV Rack Unity MR Client

This folder contains the Unity/Meta Quest 3 client used in the VeryVCV Rack prototype. The client receives semantic patch snapshots exported by the VCV Rack Bridge, reconstructs Rack modules as mixed-reality panels and controls, and exchanges runtime parameter-control messages with Rack through OSC/UDP.

The Unity client is provided as research-prototype source material accompanying the paper. It is intended to document the implementation architecture and the scripts used for the reported tests, rather than as a polished standalone Unity package.

## Main components

* `VeryVCVSnapshotLoader` retrieves the JSON patch snapshot from the Rack-side Bridge through HTTP and triggers scene reconstruction.
* `VeryVCVOscListener` receives OSC notifications and parameter updates from the Bridge.
* `VeryVCVOscSender` sends parameter-control messages from the MR client to the Bridge.
* `PatchSnapshotMapper` converts the exported JSON snapshot into the Unity runtime patch model.
* `GenericModuleSpawner` generates MR module panels, controls, labels, and jacks from the mapped patch description.
* `ControlPrefabRegistry` maps semantic control roles to reusable Unity prefabs.
* `ButtonBehaviour`, `SliderBehaviour`, and `KnobBehaviour` implement the current hand-interaction logic for reconstructed controls.
* Value adapters update the visual state of knobs, sliders, labels, and jacks from normalized parameter values.

## Communication
The client uses two communication paths:

- HTTP is used to retrieve the current JSON patch snapshot from the Bridge.
- OSC over UDP is used for runtime notifications, parameter-control messages, parameter updates, and profiling messages.

In the prototype configuration, the relevant ports are:
```text
Bridge HTTP snapshot endpoint: 5510
Quest OSC listener:           5511
Bridge OSC listener:          5512
```

The IP address of the computer running VCV Rack must be configured in the Unity scripts or inspector fields before running the client.

## Dependencies
The client was developed for Meta Quest 3 in Unity and uses Meta XR / Oculus Interaction components for hand-based interaction. The repository does not vendor Unity, Meta XR SDK packages, or external package caches. These should be installed and configured in a Unity project before importing or using the provided assets.

The project also uses TextMeshPro for labels.

## Current scope

The current implementation supports:

- loading semantic patch snapshots generated by the VeryVCV Bridge;
- reconstructing Rack modules as MR panels;
- mapping semantic roles to reusable MR controls;
- bidirectional parameter-level synchronization through OSC on macOS;
- hand-tracking interaction for buttons, sliders, and knobs;
- visual reconstruction of labels and jacks.

## Evaluation-related files

`ButtonBehaviour_test.cs` is an experimental variant used for the video-based observable responsiveness test. It is not required for the main MR client workflow.
